This repository is a curated collection of my work in **Semantic Web Technologies** and **Data Engineering**, completed through the **dkglab** curriculum.

---

## 🚀 Projects & Assignments (A1 - A6)

### 🏗 Ontology & Modeling
* **Assignment 1 & 2: Domain Modeling & RDF Schema**
    * Designed ontologies to represent real-world domains with semantic clarity.
    * Implemented **RDF/Turtle** serializations to define entities, classes, and properties.
* **Assignment 3: Web Ontology Language (OWL)**
    * Leveraged **OWL** for logic-based constraints and automated reasoning.
    * Defined transitive, symmetric, and functional properties to enhance graph intelligence.

### 🔍 Data Querying & Integration
* **Assignment 4: SPARQL Querying**
    * Developed complex **SPARQL** queries to extract insights from triple stores.
    * Performed federated queries to integrate local data with global hubs like **Wikidata** and **DBpedia**.
* **Assignment 5: Linked Data & Mapping (RML)**
    * Transformed heterogeneous data (JSON, CSV, XML) into high-quality RDF triples.
    * Focused on data interoperability and the "Linked Data" principles.

### 🌐 Knowledge Graph Applications
* **Assignment 6: Knowledge Graph Reasoning & Systems**
    * Built a functional layer to utilize the constructed Knowledge Graph.
    * Explored how semantic metadata can power smarter search and recommendation systems.
