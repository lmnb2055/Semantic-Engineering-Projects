## 🚀 Projects & Assignments (A1 - A6)

### 🏗 Ontology Modeling & Logic (A1, A2 & A4)
* **Domain Modeling:** Defined scope and purpose for data models. Translated textual information into graph-structured descriptions (Nodes & Directed Edges).
* **RDF Schema (RDFS):** Implemented **RDF/Turtle** serializations. Defined class hierarchies (`rdfs:subClassOf`) and property constraints (`rdfs:domain`, `rdfs:range`) to create formal vocabularies.
* **Inference Engine:** Used RDFS semantics to automatically infer new triples (e.g., identifying sub-class relationships and property types).

### 🔍 Data Querying & Integration (A3 & A5)
* **Web Architecture & Linked Data:** Explored URI persistence, HTTP 303 redirects, and **Content Negotiation** (JSON-LD, Turtle, N-Triples) using tools like `curl` and Wikidata.
* **SPARQL Querying:** Developed complex queries to extract insights from triple stores (e.g., NC Gazetteer).
    * *Skills:* Pattern matching, Filters, Optional patterns, and Aggregations.
    * *Federated Queries:* Integrated local data with global knowledge hubs like **Wikidata** and **DBpedia**.
* **Vocabulary Mapping:** Performed cross-vocabulary mapping (e.g., mapping **Schema.org** to **Dublin Core**) using `CONSTRUCT` queries to enhance interoperability.

### 🛡 Validation & Advanced Reasoning (A6)
* **SHACL Validation:** Authored **SHACL (Shapes Constraint Language)** shapes to enforce data quality. Implemented validation reports to ensure RDF data conforms to specific structural and cardinality constraints.
* **OWL Ontology:** Leveraged **OWL 2** for logic-based automated reasoning, enabling the system to "reason" about domain knowledge and enrich the graph automatically.
